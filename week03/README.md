# 3주차 - 셸 스크립팅과 로컬 AI 서비스 실행

## 💡 오늘 배운 핵심 내용

### 1. 왜 셸 스크립트(Shell Script)를 쓸까?
- **자동화의 필요성**: 반복적인 작업(로그 백업, 날짜별 파일 정리, 오류 개수 카운트 등)을 사람이 직접 하면 10분씩 걸리고 실수가 무조건 발생함. 반면 스크립트를 제대로 짜두면 기계가 수백만 번을 해도 실수 없이 순식간에 처리해 줌.
- **자주 겪는 에러 해결**:
  - `Permission denied`: 실행 권한이 없어서 발생하는 문제라 `chmod u+x 파일이름.sh`로 권한을 주면 해결됨.
  - `Command not found`: 현재 경로의 스크립트를 실행할 때는 그냥 이름만 치면 안 되고 반드시 `./파일명.sh`처럼 현재 위치를 명시해야 함 (환경변수 `PATH`에 등록되어 있지 않기 때문).

### 2. Ollama와 Qwen 모델로 로컬 AI 띄우기
- **Ollama**: 로컬 환경에서 LLM(대규모 언어 모델)을 쉽게 설치하고 실행할 수 있게 해주는 오픈소스 플랫폼.
- **Qwen (`qwen3:0.6b` 또는 `1.7b`)**: 알리바바에서 만든 언어 모델로, 이번 실습에서는 텍스트 질문/답변 테스트용으로 가벼운 모델을 다운받아 사용함.
- **구동 구조**: 웹 브라우저(`localhost:8000`) ➡️ 파이썬 웹 앱(`chat.py`) ➡️ Ollama 서버(`127.0.0.1:11434`) 순서로 요청과 응답이 오감.
- **모델 변경**: `nano chat.py`를 열어서 `MODEL` 변수 부분을 원하는 모델명(예: `qwen3:1.7b`)으로 수정하면 다른 용량의 모델도 쓸 수 있음.
