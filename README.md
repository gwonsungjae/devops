# DevOps

2026-2학기 DevOps 실습

## 📌 주차별 내용

* [Week 01 - 실습 환경 구축과 버전 관리 기초](./week01/)
  * 가상화 기술(VM vs 컨테이너)의 차이를 이해하고 WSL2 Ubuntu 환경 구축 및 Git/GitHub 기본 사용법 습득
* [Week 02 - 셸 스크립팅](./week02/)
  * Shebang(`#!/bin/bash`), 실행 권한, 환경 변수와 조건문을 활용한 자동화 스크립트 작성
* [Week 03 - 자동화와 협업](./week03/)
  * `grep`, `find`, 파이프(`|`) 기반의 파일/로그 검색, 프로세스 관리 및 GitHub PR Conflict 해결
* [Week 04 - 네트워크](./week04/)
  * IP, 포트, DNS 기본 구조 이해 및 `curl`, `ss`, `dig` 도구를 활용한 네트워크 상태 점검
* [Week 05 - 도커 기초](./week05/)
  * 컨테이너 격리 원리(Namespace/cgroup) 이해 및 `docker run`, `ps`, `logs` 등 기본 CLI 활용
* [Week 06 - 도커파일](./week06/)
  * `Dockerfile`을 이용한 실행 환경 코드화(IaC), 레이어 캐시 최적화 및 GHCR/Docker Hub 배포
* [Week 07 - 도커 컴포즈](./week07/)
  * `compose.yaml`을 통한 멀티 컨테이너(앱, Redis, Nginx) 선언적 관리, 볼륨 활용 및 Healthcheck 설정
